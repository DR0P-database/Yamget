# Сторонние компоненты

При установке из исходников `uv` загружает Python-зависимости отдельно. `aria2c` устанавливается системным пакетным менеджером.

| Компонент | Для чего используется | Лицензия |
| --- | --- | --- |
| `yandex-music` | Клиент API Яндекс Музыки | [LGPL-3.0-only](https://github.com/MarshalX/yandex-music-api/blob/main/LICENSE) |
| `mutagen` | Чтение и запись тегов MP3 | [GPL-2.0-or-later](https://mutagen.readthedocs.io/en/latest/) |
| `pathvalidate` | Очистка имён файлов и папок | [MIT](https://github.com/thombashi/pathvalidate/blob/master/LICENSE) |
| `aria2` | Загрузка аудио отдельным процессом | [GPL-2.0-or-later с исключением для OpenSSL](https://github.com/aria2/aria2/blob/master/COPYING) |

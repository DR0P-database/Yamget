# Yamget

CLI-загрузчик треков, альбомов и плейлистов Яндекс Музыки в MP3.

## Что уже работает

- Загрузка по ссылке, ID трека или ключу плейлиста. Поддерживаются также старые плейлисты с числовым ID и владельцем.
- Выбор битрейта MP3, каталога загрузок и шаблона имени файла.
- Запись тегов, обложки и текста песни, когда они доступны.
- Пропуск уже скачанного файла, перенос существующей копии при смене шаблона и принудительная повторная загрузка через `--overwrite`.
- Последовательная обработка альбомов и плейлистов. Ошибка отдельного трека не останавливает очередь.

## Ограничения

- Только MP3. FLAC, AAC/M4A, перекодирование и отдельные файлы LRC пока не поддерживаются.
- Управление через CLI. TUI, GUI, плеера, поиска по каталогу и синхронизации аккаунта пока нет.
- Очередь и индекс существуют в пределах текущего запуска. Массовая перестройка библиотеки и автоматическое восстановление переносов после аварийного завершения не поддерживаются.

## Быстрый запуск

Установите Python 3.11+ и [aria2](https://aria2.github.io/#download) (`aria2c` в `PATH`). Если у вас есть uv, выполните из корня репозитория:

```bash
uv run --locked --no-editable music-download 123456
```

Замените `123456` на ID своего трека. По умолчанию MP3 сохраняется в `downloads/`.

При первом запуске в терминале Yamget предложит открыть страницу Яндекса и ввести одноразовый код. После подтверждения CLI сохранит токен в `.env` в текущем каталоге и продолжит загрузку. Следующие запуски из этого каталога используют сохранённый токен. Если задана переменная окружения `YANDEX_MUSIC_TOKEN`, она имеет приоритет.

### Запуск без uv

Из корня репозитория в Bash:

```bash
python3 -m venv .venv-pip
source .venv-pip/bin/activate
python -m pip install ./music_download ./downloader_app
music-download 123456
```

В новом терминале снова активируйте окружение командой `source .venv-pip/bin/activate`.
